# Brain Quest 3D — Godot edition

This is the **native Godot 4 prototype**, separate from the existing HTML/Three.js website in the repository root. The GitHub Pages website continues to work as before.

## Open on Android
1. Install the official Godot 4 Android editor.
2. Download this repository as ZIP from GitHub and extract it using Files/My Files.
3. In Godot Android editor, choose **Import** and select `godot/project.godot`.
4. Open the project and press **Play**.

## Included
- True 3D scene rendered in Godot 4 using procedural meshes and lights.
- Three prototype maze layouts with key, floor switch, locked door, and goal portal.
- On-screen touch controls, restart, English/Arabic toggle, and hints.
- No downloaded assets required.
