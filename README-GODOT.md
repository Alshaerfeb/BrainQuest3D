# Brain Quest 3D — Godot prototype

This is an **experimental Godot 4 project**, on a separate branch from the existing GitHub Pages release.

## Run
1. Import project.godot into Godot 4.3+.
2. Run the project (F6/F5).
3. Move Pip using the on-screen arrows or keyboard arrow keys.
4. Collect the key, push the movable stone onto the pink pressure switch, and reach the glowing exit.

The geometry is generated in code; no paid assets are required. This is a **first playable systems prototype**, not the cinematic final art. GitHub Pages cannot directly run a Godot source project: a Godot Web export is required, and export templates / build automation must be configured separately.
